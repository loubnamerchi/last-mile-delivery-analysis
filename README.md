# Last-Mile Delivery Operations Analysis

## 📌 Project Overview

An end-to-end data analytics project focused on analyzing last-mile delivery operations, identifying operational bottlenecks, understanding delivery performance, and generating actionable business insights.

## 🎯 Objectives

- Analyze delivery performance
- Identify operational bottlenecks
- Investigate late deliveries
- Analyze delivery time and efficiency
- Understand factors affecting delivery performance
- Generate actionable business recommendations
- Build professional visualizations and dashboards

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn
- Jupyter Notebook
- Git & GitHub
